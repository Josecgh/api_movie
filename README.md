# 🎬 Movies REST API - Spring Boot

API RESTful para gestión de películas desarrollada con Spring Boot, JPA/Hibernate y base de datos relacional.

## 🚀 Requisitos e Instalación
- **Java 17** o superior
- **Maven 3.8+**

```bash
# Clonar repositorio
git clone [https://github.com/Josecgh/api_movie.git](https://github.com/Josecgh/api_movie)
cd movies-api

# Ejecutar proyecto
mvn spring-boot:run
